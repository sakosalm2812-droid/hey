# Dictation Edit Proposals

`HEY.voice.createDictationEditSession` creates an account-bound, locale-aware edit session using a detached snapshot of the resolved dictation preferences. Pass the current explicit application ID to select its field-wise locale override. Later preference edits do not change an open edit session.

`propose({ sourceText, utterance })` first routes the utterance through the canonical `understandVoiceCommand` classifier and accepts only an `Edit` intent that requires preview and confirmation. Recognized punctuation requests are applied locally for English, French, Spanish, Arabic, Persian, Urdu, Chinese, and Japanese. Other edit instructions require a caller-provided `rewriteProvider.proposeRewrite({ text, instruction, language, applicationId, signal })` adapter; its result is treated as untrusted data and must contain a bounded plain-text result. At most two rewrite proposals may be in flight per session. Destroying the edit session aborts active provider requests and discards late results.

The returned immutable proposal exposes both source and proposed text with `status: "preview_required"`. It does not modify an editor, insert text, submit a message, or call an application adapter. The caller must separately call `confirm(proposal, { confirmed: true, currentText, applicationId })`; confirmation is denied if the user has not explicitly confirmed, the source text or application changed, the account changed, or the proposal was already used. A successful confirmation only returns the approved text with `inserted: false` and `submitted: false` so the caller remains responsible for any later action.

The rewrite adapter receives dictated text. The caller must disclose its processing behavior and obtain any required consent before using an adapter that sends text outside the current runtime. No live rewrite provider, browser insertion, global shortcut, or cross-app input was exercised here. The command classifier's edit grammar and localized punctuation phrases are bounded supported patterns, not general multilingual speech understanding.
