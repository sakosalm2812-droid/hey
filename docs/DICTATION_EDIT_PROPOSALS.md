# Dictation Edit Proposals

`HEY.voice.createDictationEditSession` creates an account-bound, locale-aware edit session using a detached snapshot of the resolved dictation preferences. Pass the current explicit application ID to select its field-wise locale override. Later preference edits do not change an open edit session.

`propose({ sourceText, utterance, targetId, selectionDigest })` requires the current editor target and a bounded digest derived by the host from the exact selected text. An explicit `insert`, `expand`, or `use snippet` command followed by an exact saved snippet name creates a snippet proposal from the session's app-scoped preference snapshot. Other utterances go through the canonical `understandVoiceCommand` classifier and require an `Edit` intent that requires preview and confirmation. Recognized punctuation requests are applied locally for English, French, Spanish, Arabic, Persian, Urdu, Chinese, and Japanese. Other edit instructions require a caller-provided `rewriteProvider.proposeRewrite({ text, instruction, language, applicationId, targetId, selectionDigest, signal })` adapter; its result is treated as untrusted data and must contain a bounded plain-text result. At most two proposals may be in flight per session. Destroying the edit session aborts active provider requests and discards late results.

The returned immutable proposal exposes source and proposed text with `status: "preview_required"`. It does not modify an editor, insert text, submit a message, or call an application adapter. The caller must preview it and separately call `confirm(proposal, { confirmed: true, currentText, applicationId, targetId, selectionDigest })`, recomputing the digest from the current selection. Confirmation is denied if the user has not explicitly confirmed, the source text, account, application, target, or selection digest changed, or the proposal was already used. A successful confirmation only returns the approved text with `inserted: false` and `submitted: false`; the caller remains responsible for any later action.

The rewrite adapter receives dictated text. The caller must disclose its processing behavior and obtain any required consent before using an adapter that sends text outside the current runtime. No live rewrite provider, browser insertion, global shortcut, or cross-app input was exercised here. The command classifier's edit grammar and localized punctuation phrases are bounded supported patterns, not general multilingual speech understanding.
